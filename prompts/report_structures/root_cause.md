# Report structure — root_cause / 원인분석 (template)

Status: not yet authored. When the team defines this, this file should
describe what a "root_cause" (원인분석) question's report should emphasize
differently from other intents — e.g. which sections to prioritize, what
should be highlighted (causal chain, contributing factors, evidence tying
cause to effect), and any framing guidance for the audience-adaptation step
to use.

Until then this file intentionally has no differentiation content in it —
`core/report_planner` only checks that this file exists and attaches its
raw text as `ReportPlan.intent_emphasis`; nothing currently reads or acts
on it beyond that.
