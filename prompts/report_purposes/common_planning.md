# Common Report Planning — Question First

This instruction is shared by all four report purposes. Purpose defines the
broad decision context; `question_answer_type` and explicit wording define the
reader's first substantive question.

## Planning order

`QUESTION FIRST → DIRECT ANSWER → NARRATIVE → SLOT → BLOCK → LAYOUT`

1. KEY is an executive answer to the user's question, not a generic market
   preface. Every block below must explain or support that answer.
2. Decide the reader flow before choosing a block. Read top-to-bottom and
   left-to-right as `Answer → Evidence → Analysis → Decision/Action`.
3. An explicit comparison, time trend, cause, response, recommendation or
   strategy request overrides the purpose's default entry slot.
4. One slot answers one named question. Choose its representative first, then
   at most one companion that shows different evidence. Never repeat the same
   insight in KPI, chart and prose.
5. Remove unsupported optional slots. Never create a number, relationship,
   SWOT quadrant or action merely to complete a layout.
6. Direct measurements are facts. AI-derived importance, fit, priority or
   recommendation must remain traceable to supplied evidence and be labelled
   as AI judgement in the dashboard; never present it as a surveyed value.
7. Data count selects a component variant, not the story: one supported SWOT
   quadrant is a solo panel, two a duo, three a trio, and four a 2×2.
8. Preserve the 4-unit grid and slot order. Do not pull a later slot forward to
   fill whitespace. Keyword frequency remains a compact bottom-right support.
9. For every planned slot, preserve `question_answered` and `why_here`; reject
   a slot that does not answer the user or duplicates another slot's question.

## Answer-type overrides

- `status`: Current Snapshot → Trend → Comparison → Details → Drivers.
- `compare`: Comparison → KPI → Details → Trend → Implication.
- `trend`: Trend → KPI → Drivers → Comparison.
- `cause`: Problem Evidence → Cause Structure → Importance → Evidence → optional Improvement.
- `issue_response`: Problem → Cause → Impact → Options → Recommendation → optional Execution.
- `recommend`: Target → Candidates → Comparison → Fit → Recommendation → optional Execution.
- `strategy`: Current Position → Future Change → Opportunity → Competitive Fit → Strategic Choice → Recommendation → Execution → optional Risk.

Audience changes vocabulary, density and emphasis only after this reasoning
order is fixed. It must not move a preferred market section ahead of the cause
or recommendation the user explicitly asked for.
